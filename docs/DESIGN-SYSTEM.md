# 原创 UI 设计系统

品牌 OioProbe，标语 **Your servers, at a glance.**。以原创心电式观测标记、雾白画布和清晰的资源数字建立视觉识别；不复制第三方主题源码、背景图或组件。

## 0.1.2 视觉调整

- 顶部品牌、居中分段导航、右侧操作构成稳定的三段布局。
- 概况去掉嵌套卡片，使用细分隔线与 25–34px 数字区分层级。
- 地图采用本地点阵地理轮廓，桌面左侧为地区概况，右侧显示地图；手机保留地图和筛选，省去介绍文案。
- 桌面节点三列、中屏两列、手机一列。节点卡片按身份、资源、流量、运行时间排列；CPU/内存/磁盘横排，关键读数 20–22px。
- 离线/过期节点仍显示空读数；没有装饰性假曲线或虚构网络连线。
- 清理旧侧栏和重复覆盖样式，深浅主题共用同一套结构。

## 界面重设计（极简 / 专业化）

- 统一 token：表面分三级（surface / surface-2 / surface-3），语义色新增 `--danger`；所有文字色在 surface 与 surface-2 上满足 WCAG AA。
- 字号下限 12px；正文 14px，页面标题 24px，概况数字 28px，卡片读数 20px，均使用 tabular-nums。
- 页面标题按页面给出具体说明，去掉装饰性 eyebrow 与地图营销文案；演示模式提示改为淡蓝信息条。
- 顶栏 60px；连接状态在窄屏收为圆点（文字保留给读屏）；移动菜单支持 Esc 关闭。
- 节点情况增加在线 / 过期 / 离线健康条；地图左侧改为可筛选的地区列表（含本地化地区名），收起地图后仍以标签行保留筛选。
- 状态筛选显示各状态数量（随搜索、分组、地区筛选联动）；卡片 / 列表视图偏好保存在浏览器。
- 节点卡片：系统信息并入副标题；资源条统一使用监控蓝，>80% 琥珀、≥90% 红色；流量为两块浅底读数；离线节点使用红色状态并弱化旗帜。
- 列表视图为单行表格式布局；详情页节点名为 h1，CPU 历史按实际像素宽度绘制，自动选择整齐刻度，并显示当前 / 平均 / 峰值。
- 主题默认跟随系统，设置页提供 浅色 / 深色 / 跟随系统；首帧前即应用主题，避免闪烁。

配色原则：界面框架使用中性微暖灰，把颜色留给含义——监控蓝只用于操作与资源条，绿 / 琥珀 / 红只表示状态，且总与文字标签或图标同时出现。数值与标签保持墨色，旁边的圆点或色条承担状态。白字只放在加深一级的 `--accent-strong` 上（5.39:1）；彩色文字使用各自的 `*-text` 色阶。下表全部文字组合均经计算满足 WCAG AA（最低 5.33:1）。

| Token | 浅色 | 深色 | 用途 |

| --background | #f6f6f4 | #0d0d0d | 页面底色 |
| --surface | #ffffff | #1a1a19 | 卡片与面板 |
| --surface-2 | #f3f3f1 | #222221 | 分段控件、流量块、标签 |
| --text | #151514 | #f0efec | 主要文字 |
| --muted | #5f5e5a | #aeada4 | 次级信息 |
| --border | #e6e5e0 | #2c2c2a | 细边界 |
| --accent | #2a78d6 | #3987e5 | 资源条、图表、焦点、下载 |
| --accent-strong | #256abf | #256abf | 主按钮底色（白字） |
| --accent-text | #1f62b5 | #86b6ef | 链接与选中项文字 |
| --upload | #eb6834 | #d95926 | 上传图标 |
| --success | #0ca30c | #0ca30c | 在线（圆点 / 健康条） |

状态徽章使用对应状态的浅色底（`--*-soft`）+ 墨色文字 + 状态色圆点。CPU 历史图支持悬停十字线与数值提示。

卡片与面板圆角 12px，主要控件 8px；间距以 4/8/12/16/24/32px 为基准。正文系统字体，数字使用 tabular-nums。
桌面节点三列，≤1180px 两列，≤680px 一列；顶部导航在 ≤680px 切换为下拉菜单；320px 起可操作。移动端搜索独占一行，排序/分组/视图操作排成下一行。

地图采用 D3 地理投影 + world-atlas/Natural Earth 本地轮廓，支持 2D 世界图、3D 球面投影、旋转/缩放/重置/收起及地区筛选。无需 WebGL、第三方瓦片、IP 定位或 API key。标记为地区参考位置，不声称节点精确坐标；未收录参考坐标的地区仍可用标签筛选。

组件：Button（Slot + cva）、Meter、Status、NodeCard、World、空/加载/错误状态。
深浅色使用 CSS variables；localStorage 仅保存版本化显示偏好，浏览器禁存储时仍可使用。
状态同时使用文字与圆点，提供可见键盘焦点、控件 aria-label、skip link 和导航 aria-current。
卡片 hover 仅轻移 1px；prefers-reduced-motion 下关闭 transition。无循环装饰动画。
`#/design` 可查看实际 tokens 与组件状态。
