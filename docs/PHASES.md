# 阶段范围与退出标准

本轮收到明确授权的范围：技术基线、API 兼容性验证、原创 UI 设计系统、页面骨架。
此前方案没有展开每个阶段的具体 checklist；以下按此次指令固化，后续阶段不混入本轮。

| 阶段 | 交付 | 退出证据 |
| --- | --- | --- |
| Phase 0 | 版本/许可证锁定、架构边界、公共 API/WS 兼容层、隔离内核验证、可复现工具 | 代码测试与 native-compat.json |
| Phase 1 | 原创设计 tokens、总览/节点列表/详情、网络/告警占位、设置/设计系统、移动端、标准主题包 | 类型/lint/build、浏览器功能与无溢出、截图、原生主题静态资源检查 |
| Phase 2 | 本地真实 Agent / 真实指标、完整历史图表、基础 Ping、筛选与实时数据优化 | 各操作系统 Agent 对照、断线恢复、持久化曲线 |
| Phase 3 | 告警、通知、权限/隐私回归、部署配置与备份恢复 | 隔离环境端到端、安全回归、备份恢复 |
| Phase 4 | 用户另行授权后生产灰度 | 生产授权、真实节点、24h 稳定性、监控/回滚 |

Phase 0/1 明确排除：生产域名部署、任何真实 VPS Agent 安装、生产凭据、告警发送。
代码遵循 main 主线。提交与远端推送分别记录；远端不存在时不声称已推送。
